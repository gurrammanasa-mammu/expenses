# Ledger — Expense Tracker

A responsive, browser-based personal finance dashboard for tracking income and expenses.

## Run it

Open `index.html` in a modern browser. No build step, dependencies, or server are required.

## Features

- Monthly income, expense, and balance summaries
- Add income and expense transactions with categories and dates
- Search and filter your transaction history
- Cash-flow chart and spending-by-category breakdown
- Adjustable monthly budget with a progress indicator
- Export the selected month's transactions as CSV
- Automatically saves data in your browser's local storage

All data stays in the current browser and device; this demo does not use a remote database or account sync.
